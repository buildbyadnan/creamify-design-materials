# Creamify x Darleys - FINAL package (red + cream, rooster-comb handle)

**STATUS: CONCEPT - DIMENSIONS/DIELINE TO BE CONFIRMED.** Design, artwork and template are complete. Box size and structure are ASSUMED, so the artwork is print-ready only after the box manufacturer confirms or supplies their dieline.

## Design summary
- Client's rooster (vector trace) tilted 9 degrees; its red comb is the die-cut carry handle with an 80 x 20 mm finger slot. Back panel mirrors the front so both handle plies match when glued.
- Cream label: BROASTED CHICKEN, THE REAL BROAST, and the **Creamify x Darleys** lockup (bold x between the two logos). Ends: cream with large red type and the same lockup.
- Both logos are used unaltered in their own colours on transparent backgrounds (Creamify from the client's vector PDF; Darleys from the supplied PNG, white background removed).

## Known limitation (decision for the client)
The yellow Creamify letters on the cream label measure only about 1.5:1 contrast. They are readable at this size but weaker than the Darleys logo. Option 03 (dark plate) fixes this without altering the logo.

## Assumed geometry (mm)
Front/back 250 wide; ends 164 deep; body 132 high; roof panel 100 (rise 60, run 80); handle 70 above the ridge (22 mm glue strip + comb tab); bottom flaps 85/55; glue tab 18; bleed 3; safe zone 6. Folded about 250 x 164 x 262 mm with handle.

## Checks run
Single closed cut outline; finger slot has 9.4 mm of material around it; all text and logos inside the 6 mm safe zone and clear of folds; PDF page size 876 x 439 mm; mockups regenerated from the same artwork.

## To confirm before print
1. Manufacturer dieline, size, board, bottom lock, bleed, print method; that they can die-cut the comb outline and a double-ply handle of this shape.
2. Original vector rooster (current one is an automatic trace of a 308 x 612 px image).
3. Vector Darleys logo if available (supplied PNG is about 600 dpi at print size).
4. Written approval of the co-branded lockup from both brands, plus any brand guidelines (minimum size, clear space) - none were supplied.
5. BROASTED trademark licence (Broaster Company states it is registered to licensed operators).
6. Colours are RGB references: match to Pantone/CMYK and approve a physical proof.
